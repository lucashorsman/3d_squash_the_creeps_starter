# CRUSH EM UP
CRUSH EM UP is a simple, 3D game built in Godot.
Controls are as follows: WASD/arrows to move, Space to jump, and Shift to use items. The goal of the game is to survive as long as possible, while taking out as many creeps as you can! Go for a high score!
Play by cloning and opening in Godot, or play on itch.io!
